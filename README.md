## What I Learned

### Frontend (HTML, CSS, JavaScript)
* **HTML Structure:** How to use semantic tags for better page organization.
* **CSS Class Management:** Moving from single, bulky classes to multiple specific classes.
  * *Example:* Changed from `class="country-selector-wrapper"` to `class="country-selector-wrapper dark-ft toggle-ft dark-border toggle-border c-pointer"`.
* **JavaScript:**
  * **Core Logic:** Working with events, anonymous functions, and arrow functions.
  * **API & Data:** Using `async/await` and the **Fetch API** to handle form submissions.
  * **Animations:** Using the **GSAP** library for smooth UI movement.
  * **Validation:** Using Regular Expressions (Regex) to check user input.

### Backend (PHP & MySQL)
* **Server Logic:** Processing data and handling server-side validation.
* **Databases:** Using **PDO** to safely connect and interact with a MySQL database.
* **Email:** Setting up **PHPMailer** with Gmail SMTP to send emails through the site.

### Data & Infrastructure
* **JSON:** Architecture of both flat and nested JSON structures for data exchange.
* **DevOps & DNS:** * Configured **Cloudflare Email Routing** and DNS management for custom domain professional emails.
  * Set up custom SMTP endpoints to bridge PHP mail functionality with professional domain aliases.

### Data & Tools
* **JSON:** Building flat and nested data structures.
* **Email & DNS:** * Setting up **Cloudflare Email Routing** and managing DNS records.
  * Configuring a custom domain email to work with PHP scripts.
* **Documentation:** Learning how to read and follow technical guides for installing/integrating new tools and dependencies.
